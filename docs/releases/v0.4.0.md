# SuniCapture 0.4.0

## English

SuniCapture is now available for Linux x64, with a native interface for screenshots, annotations, a local library and MP4 recording. English is also the primary language of the repository presentation and documentation; French remains available.

- **Linux installer:** `SuniCapture-0.4.0-linux-amd64.deb` for Debian 12+ / Ubuntu 22.04+ x86_64.
- **Linux archive:** `SuniCapture-0.4.0-linux-x64.tar.xz`, using system Python, GTK and multimedia dependencies.
- **Windows portable:** `SuniCapture-0.4.0-win-x64.zip`, including .NET.
- **Integrity:** compare your download with the matching entry in `SHA256SUMS.txt`.

Install the Linux package with `sudo apt install ./SuniCapture-0.4.0-linux-amd64.deb`, then open SuniCapture from the application menu. See the [Linux guide](https://github.com/lmdanavanem/SuniCapture/blob/v0.4.0/docs/linux.md) for dependencies, shortcuts and storage.

The validated Linux capture session is X11/Xorg. Wayland support through system permission dialogs and PipeWire is experimental and depends on your desktop backend. System playback audio depends on an available playback monitor; the microphone is never selected.

Both platforms provide French/English, light/dark themes, About, help and preferences. Application files and capture libraries are separate; an update keeps existing captures. Windows capture and recording workflows are retained.

## Français

SuniCapture est désormais disponible pour Linux x64 : captures, annotations, bibliothèque locale et enregistrement MP4. La présentation principale du dépôt est en anglais, avec une documentation française disponible.

- **Debian 12+ / Ubuntu 22.04+ :** téléchargez le `.deb`, puis lancez `sudo apt install ./SuniCapture-0.4.0-linux-amd64.deb`.
- **Archive Linux :** extrayez le `.tar.xz` et lancez `sunicapture` après installation des dépendances décrites dans le guide Linux.
- **Windows :** extrayez tout le ZIP, puis ouvrez `SuniCapture.exe`.

Les parcours Linux validés utilisent X11/Xorg. Le support Wayland est expérimental et dépend du portail du bureau. Les captures personnelles sont conservées lors d'une mise à jour. Les sommes de contrôle sont fournies dans `SHA256SUMS.txt`.
