SuniCapture 0.3.0 is the first public release: local screenshots, annotations and MP4 screen recording for Windows x64, with French and English interfaces.

## Download

- Download **SuniCapture-0.3.0-win-x64.zip**, extract the complete folder and run **SuniCapture.exe**.
- .NET is included. Keep the accompanying files next to the executable.
- **SHA256SUMS.txt** contains the archive's SHA-256 checksum.

## Included

- Region, all-display and selected-window screenshots, with optional capture delay.
- Import, paste and drag images into a persistent local library.
- Arrows, shapes, pen, highlights, text, numbered steps, opaque redaction and crop.
- Automatic annotation saving, undo/redo, PNG/JPEG/BMP/PDF export and image copying.
- Primary-display H.264 MP4 recording at 30 fps, optional system playback audio, floating stop control and video preview. Microphone disabled.
- Favorites, search, rename and restorable Trash.
- Immediate FR/EN switching, light/dark themes, About, preferences and built-in help.

## Validation and limits

Local validation passed **36 core checks and 94 UI/recording checks**, plus **307 FR/EN resource checks**. The recording workflow produced a finalized MP4 decoded by Windows. Continuous integration also verifies the Windows build and core checks.

Windows x64 is required. Video recording may require Microsoft Visual C++ x64 and Media Foundation, particularly on Windows N/KN. Mixed-DPI displays and system audio need hardware-specific qualification. Scrolling capture, OCR, webcam, video trimming and cloud destinations are not included. Saved annotations are flattened.

Files remain in `%LOCALAPPDATA%\SuniCapture`. No account, application telemetry or capture uploads. To update, quit the previous version using its notification icon, then use the new portable folder. The library is stored separately from the app.
