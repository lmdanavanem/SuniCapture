# SuniCapture 0.4.1

## English

This update refines the Linux interface, with a compact title bar, correctly sized window controls, readable menus and consistent toolbar icons.

- Minimize, maximize, restore and close use native GTK actions in a single title bar.
- French/English menus, navigation and dialogs stay readable in light and dark modes.
- Smaller desktops and 200% interface scaling receive additional layout checks using Ubuntu's Yaru theme.
- Screenshot, annotation, MP4 and local-library workflows remain available; updating preserves your captures.

**Ubuntu/Debian:** download `SuniCapture-0.4.1-linux-amd64.deb`, then run `sudo apt install ./SuniCapture-0.4.1-linux-amd64.deb`. An archive is also available; see the [Linux guide](https://github.com/lmdanavanem/SuniCapture/blob/v0.4.1/docs/linux.md). Windows packages carry the same version number and retain their existing interface.

Linux functional and visual checks run after installation, including complete window frames, native caption actions, menu contrast and file choosers. See the [verification scope](https://github.com/lmdanavanem/SuniCapture/blob/v0.4.1/docs/verification-0.4.1.md). Wayland capture remains experimental; the capture session qualified by the functional checks is X11/Xorg.

Verify downloaded files against `SHA256SUMS.txt`.

## Français

L'interface Linux est corrigée : barre de titre compacte, boutons réduire/agrandir/fermer aux bonnes dimensions, menus lisibles en clair et en sombre, navigation et icônes harmonisées.

Les contrôles couvrent le français, l'anglais, les petits écrans et une mise à l'échelle de 200 %, avec le thème Ubuntu Yaru. Les parcours de capture, d'annotation, de vidéo et de bibliothèque locale sont conservés.

Installez la mise à jour avec `sudo apt install ./SuniCapture-0.4.1-linux-amd64.deb`. Vos captures sont conservées. Une archive Linux x64 est aussi disponible. Le support de capture Wayland reste expérimental.
